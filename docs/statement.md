# 勘误声明（关于 dsh-router-standard 论文的理论部分）

> 发布人：yjh051108（dsh-routing-suite / dsh-router-standard / dsh-mode-boost）
> 日期：2026-08-16
> 状态：**论文保留，理论解释部分标注作废，数据与方法继续有效**

## 一、先说结论

**论文不撤回。** 论文中的**实测数据、探针方法、实验表格、工程实现**仍然有效，继续作为仓库的公开记录保留。

但论文中的**底层推演/理论解释部分**——即"双吸引子行为策略"以及由此推出的若干强归因——经反复核对后，我确认其中存在**将现象当作本质**的错误，现正式**标注作废**，不再作为结论引用。

## 二、作废范围（明确到章节）

以下内容**标注作废**：

1. **§3 理论：双吸引子行为策略（假设 A1–A4）**
   - A1"后训练刻意对齐了至少两个专家 scaffold"——**作废**。
   - A2"中间带是训练分布间隙"——**降级为待验证假说**（现象仍在，成因未证）。
   - A3"自路由不可能 by construction"——**作废**（"路径提交"是现象，"不可能"是过度推演）。
   - A4"条件化主导超过模型间差异"——**降级为现象描述**，删除"因此每个吸引子是专家且不泛化"的强解释。

2. **§6 讨论中的强归因**
   - "God/ghost duality is routing, not sampling"——**作废**。
   - "Continuity is a user-interface illusion"——**作废**。
   - "Self-routing: impossibility and its narrow exception"——**作废**，改为"自路由在弱域存在软切换残差"。

3. **README / blog 中的"刻意双模式"叙事**
   - "官方刻意设计了 spec/react 双模式"、"路由层训坏了"——**作废**。

## 三、保留有效（不受影响）

- **所有实测数据**：21 点相变探针、触发矩阵、P1–P30 实验表、词法分类结果、路由率/收敛率/深度经济数据。
- **探针方法**：probe 脚本、classifier、eval 电池。
- **工程实现**：router-standard preset、mode-boost 插件、首轮锚定、近场引导、We-lock、雷霆断路器。
- **可复现的提升**：Flash 在插件下的路由/收敛/深度提升；这些是现象层面的实测结果，不依赖理论解释成立。

## 四、修订方向（替代解释）

当前更接近证据的解释（**现象学表述**，不声称成因已证）：

> 模型原生存在"Let me"式深度推理路径；后训练阶段可能试图压出另一条"We need"式极简路径，但两者之间存在一个**未完全收敛的中间层/断层**。这个断层恰好保留了根据输入语义做软切换的残差能力。插件不是"修复路由"，而是**把这个断层当作自适应门控**来使用：简单任务滑向"We need"（高效），复杂规划滑向"Let me"（深度）。

### 心路历程（重要，请完整阅读）

1. **最初**：观察到 V4 Flash 两种差异极大的思维链形态（"We need" 极简高效 / "Let me" 长链深推），我以为是官方刻意设计的双模式，只是路由层没训好。
2. **第一次修正**：意识到这个归因很可能错了——更接近真相的是"一条原生深度路径 + 一条被后训练强行压出但未收敛的极简路径"，两者之间存在**断层**。
3. **关键修正（本次）**：**这个断层本身就像一层路由层**。我实际做的，正是把断层当作路由层来用——在弱域上注入语义特征，让模型在 "Let me" 与 "We need" 之间**自路由**。插件性能提升（路由率、收敛率、深度）是这一用法的实测结果，**这条心路历程成立**。
4. **陷阱带也因此解释通了**：中间混合带（0.2–0.45）是**断裂带**——两条行为轨迹（"Let me" 原生深推 / "We need" 后压极简）在此处相遇、错位、断裂。它不是一个"真空间隙"，而是**两个训练板块之间的断裂区**；这解释了为什么它既不能稳定执行、又保留了切换残差。
5. **待验证的假说（记下，以后再说）**：官方最优可能**既不是 "Let me" 也不是单纯的 "We need"**——这两个也许都只是过拟合形态。真正的最优可能是一个**能同时触发两者能力的统一思维链**。此假说目前无证据，仅作长期方向记录。

## 五、后续计划

1. 不再试图"训练/修复"路由层，改为**精准测量断层/训练锻炼带的边界**。
2. 受限于云端 API 无法读取隐藏状态，采用**黑盒指纹探测**：logprobs、BPE 分词边界、语义锚点，**逆向出嵌入式向量层中对路由敏感的坐标**，反向定位能将模型稳定推向 "We need" 或 "Let me" 的输入向量。
3. 将这些**路由指纹**做成插件内的动态调节旋钮，按首轮语义自动选择思维链模式；并朝"统一最优思维链"假说方向积累证据。
